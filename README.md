# 차례 — 근무표 생성기

기존 Tkinter 근무표 생성기를 브라우저에서 사용할 수 있도록 옮긴 정적 웹 앱입니다.

## 기능

- 평일만 / 주말·공휴일만 / 별도 명단 / 공통 명단과 별도 순번 / 매일 통합 순번
- 대한민국 공휴일 및 대체공휴일 반영, 임시공휴일 추가
- 미운영일 및 추가근무일 지정
- 월간 배정 미리보기와 서식이 포함된 `.xlsx` 다운로드
- 브라우저에 설정 저장, 다음 달 순번 확정, JSON 백업·복원
- 기존 PC 버전의 `rotation_state.json` 가져오기
- 모바일 화면 지원

명단이나 순번은 서버에 전송하지 않습니다. 브라우저 저장소는 기기·브라우저별로 구분되며 브라우저 데이터를 지우면 삭제됩니다. 설정 백업을 보관하세요. 미리보기와 엑셀 다운로드는 순번을 소비하지 않고, **순번 확정 · 다음 달**을 누를 때 다음 순번을 저장합니다.

## 실행 및 확인

Node.js 20 이상과 Python 3(로컬 미리보기만)이 필요합니다.

```sh
npm ci
npm run build
npm test
python -m http.server 8080 --directory dist
```

브라우저에서 http://localhost:8080 으로 접속합니다. 서버 기능이나 데이터베이스는 필요 없습니다. 정적 호스팅에 `dist/`를 올리면 실행됩니다. ExcelJS 파일도 같은 사이트에서 제공하므로 외부 CDN에 의존하지 않습니다.

## 공휴일 데이터

`dist/holidays.json`은 python-holidays 0.106의 한국 공휴일 자료(2000–2050년)로 생성했습니다. 지원 범위를 벗어난 연도는 거부합니다. 이후 확정되는 임시공휴일·법 변경은 자동 갱신되지 않습니다. UI의 공휴일 보정으로 추가하거나 아래처럼 자료를 갱신하세요.

```sh
python -m pip install holidays==0.106
python scripts/update_holidays.py
```

## 글꼴

제공된 제주돌담체 TTF는 웹 임베딩·재배포 권한이 확인되지 않아 공개 저장소에 포함하지 않았습니다. 화면은 기기의 기본 한글 글꼴을 사용합니다.

## 검증

`npm test`는 원본 Python 배정 결과로 만든 25개 사례(5개 운영 방식, 윤년, 공휴일, 연말)를 비교하며, 입력 검증·다음 달 이어받기·엑셀 재열기 및 수식 문자 안전성을 추가 확인합니다. 테스트에는 실제 근무자 정보가 없습니다.

## 라이브러리

ExcelJS 4.4.0 (MIT), python-holidays 0.106 (MIT, 공휴일 자료 생성용). ExcelJS 라이선스는 `dist/vendor/EXCELJS-LICENSE.txt`에 있습니다. `npm audit`는 ExcelJS의 uuid 의존성에 중간 등급 경고를 표시합니다. 해당 경고는 uuid v3/v5/v6의 버퍼 인수 처리에 관한 것이며 이 앱은 해당 API를 호출하지 않고 새 엑셀 파일만 생성합니다. 사용자 엑셀 파일을 불러오지 않습니다.
